## Overall seed/DB coverage summary

- **Core ICD-1 catalogue (dishes/ingredients/cuisines/tags/combos)**: production-scale, ETL'd,
  checksummed, ~99–100% coverage vs source spreadsheets. This is real data, not a fixture sample.
- **Dish-ontology aliases**: 786 rows committed across 23 seed files, but only 37 (4.7%) have a
  Founder-signed execution certificate proving live deployment (CERT-027, batch 1 only).
- **Legacy re_engine seeds (110–117, ~3,000+ rows incl. 2,952 cohorts)**: schema dropped
  (migration 047); historical record only, not live.
- **ghar_re golden-sample seeds (120–121, 736 rows)**: explicitly disclosed synthetic
  (`data_source='ai_generated'`), schema dropped (migration 050); never was production data.
- **4 raw CSV/JSON files in data/source/ (ingredient_aliases_v2, term_synonyms_v2, recipes_v1,
  dish_images_v1) are not wired into any ETL path** — sitting as apparently-unused research
  material, ~1,100+ combined rows/records never reaching the live database.
